# ChiMatcha - Mobile F&B Ordering Prototype 🍵📱

ChiMatcha is a modern mobile ordering prototype specifically designed for premium matcha tearooms. Combining an intuitive interface with dependable order handling, the application delivers a smooth, delightful digital dining experience through an adaptive UI and robust input validations.

---

## 📌 Problem Background

Ordering artisanal food and beverages through conventional mobile platforms often presents several usability hurdles:
* **Complex Menu Customization:** Artisanal drinks (like ceremonial matcha) require precise personalization (sweetness level, ice ratio, dairy alternatives, and specialty toppings) which can easily overwhelm customers if the interface is cluttered.
* **Lack of Adaptive Context:** Generic menu interfaces often display irrelevant options for specific products, causing confusion and ordering errors.
* **Order Validation Errors:** Inaccurate quantity handling and weak edge-case validation lead to frustrating checkout experiences and incorrect kitchen orders.

---

## 💡 Proposed Solution

Developing a modern, user-centric **Mobile Ordering Prototype** featuring a smart UI that automatically adapts to product categories, simplifies complex drink customization, and enforces strict input validation for a seamless ordering flow.

---

## ✨ Key Features

* **Interactive Matcha Menu & Catalog:**
  Visually rich showcase of curated matcha beverages, soft serves, and desserts with clear pricing and item descriptions.

* **Dynamic Order Customization:**
  Smart adjustment options (sweetness, ice levels, toppings) that dynamically render and adapt based on the selected product category.

* **Strict Input Validation & Cart System:**
  Real-time quantity safeguards and form validation during item selection and checkout to prevent invalid orders.

* **Secure User Authentication:**
  Reliable sign-in and sign-up flows designed to protect user identity and persist customer order preferences.

* **Adaptive & Responsive UI:**
  Intuitive layouts and micro-interactions built with modern mobile design principles for effortless navigation.
